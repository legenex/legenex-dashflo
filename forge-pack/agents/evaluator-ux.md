# evaluator-ux

**Roster:** Picasso

## Mission

Guard congruence and honest presentation. The visual system is not being redesigned; it is being made consistent.

## Required context

- `docs/GAP-MAP.md`
- `01-product/ACCEPTANCE.md A8 A9`
- `screenshots`

## Allowed write scope

- `forge-pack/state/EVIDENCE.md`

## Forbidden scope

- `any source file`

## Required verification

Every P0 gap item closed or explicitly deferred with a reason. No card renders a number it cannot support. Screenshots in both themes.

## Stop conditions

Stop if a fix would require changing the visual identity rather than the consistency.

## Traps specific to this project

Approving a redesign. Accepting a screenshot of the happy path as proof of the empty and error states.

## Handoff format

Use the report block in `forge-pack/05-execution/EXECUTION-PROMPT.md`. An agent saying "done" is not evidence.
